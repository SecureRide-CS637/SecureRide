# SecureRide: ready-to-run project

## Important limitation
The supplied dataset is **synthetic**, generated by `gen_dataset.py` from a physics-inspired simulator. It is not a collection of real scooter rides or real GPS traces. `sidewalk` labels are generated from the simulated surface index. Treat results as a simulation/feasibility study, not proof of real-world sidewalk detection.

## Windows setup (PowerShell)
Install Python 3.10 or 3.11, then from this folder run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install numpy pandas matplotlib scikit-learn joblib
```

If `py -3.11` is unavailable, install Python 3.11 from python.org or use `python -m venv .venv` with a compatible Python.

## 1. Check that the dataset is present
The `data` folder already contains `trips.csv`, `trips_meta.csv`, `secureride_windows.npz`, `norm_stats.json`, and `window_counts.csv`. You do not need to regenerate it to start.

## 2. Run the battery/surface calibration plots
```powershell
python calibration_plots.py --root data --out results
```
This creates the Fig. 2-style plots and `results/calibration_summary.txt`.

## 3. Train a quick baseline (no TensorFlow required)
```powershell
python train.py --backend sklearn --tasks sidewalk speeding --lengths 5 10 20 --hls 1 --max-train 10000 --max-eval 10000
```
This is a smoke-test/baseline, not the paper's CNN. It creates `.joblib` models under `models/`, an accuracy CSV, and a plot under `results/`.

For a broader sklearn sweep, use:
```powershell
python train.py --backend sklearn --max-train 40000 --max-eval 40000
```

## 4. Run dual-mode sidewalk evaluation
After the training command completes:
```powershell
python dualmode.py --task sidewalk --backend sklearn --results results --models models --root data
```
For speeding:
```powershell
python dualmode.py --task speeding --backend sklearn --results results --models models --root data
```
The dual-mode command requires models and a matching `results/accuracy_sklearn.csv` produced by the preceding training run. Do not run it first.

## 5. Run the actual 1D CNN (optional; slower)
Install TensorFlow in a compatible Python environment:
```powershell
pip install "tensorflow==2.13.*"
```
Then train:
```powershell
python train.py --backend keras --tasks sidewalk speeding --lengths 5 10 20 --hls 1 2 --max-train 20000 --max-eval 20000 --epochs 30
```
This runs a reduced CNN grid. The full grid is slower and may require more RAM/GPU. The project code's default L2 regularization is 1e-3; use `--l2 0.01` to match the paper's stated value.

## 6. Useful files
- `gen_dataset.py`: physics-inspired synthetic ride/battery simulator.
- `secureride_data.py`: window generation, normalization and augmentation.
- `secureride_model.py`: CNN/GRU and sklearn baseline implementations.
- `train.py`: training and held-out test evaluation.
- `dualmode.py`: quick/accurate dual-mode state machine evaluation.
- `calibration_plots.py`: sanity-check plots for the simulator.
- `data/trips.csv`: timestep-level synthetic data; includes speed/surface for labels only.
- `data/secureride_windows.npz`: precomputed windows and labels.

## Research checklist before making claims
1. Keep the trip-level train/validation/test split; do not randomly split overlapping windows.
2. Never feed `speed`, `surface`, `sidewalk`, or `speeding` as model inputs; inputs should be voltage, current, capacity.
3. Report class balance and per-class precision/recall/F1, not accuracy alone.
4. Compare against a simple baseline and ablations (e.g. no augmentation).
5. Validate on independent real scooter rides before claiming real-world sidewalk detection.
